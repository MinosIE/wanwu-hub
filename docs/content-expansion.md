## 1. 现状与差距（2026-10 盘点）

两种架构并存，扩充手法不同：

- **subjectKit（LIGHTWEIGHT）**：`physics`、`chem`、`mgmt` —— 配置驱动，加模块 = 往 `data.ts` 的 `modules[]` 追加，**最易扩充**，且已具备 `figure`/`eq`/动画/物质释义能力；`npm run data:export` 可把 `data.ts` 导出为 `public/<x>-data/data/*.json` 机器可读数据（含 llms.txt / sitemap / robots）。
- **FULL 模板**：`dynasty`、`econ`、`mind`、`thought`、`earth`、`life` —— 自带 `template.ts` + `public/<x>-data/data/*.json`。加条目 = 改 JSON（易）；**加新分类视图 = 需改模板**（重）。

## 2. 执行策略（三阶段）

- **阶段 A｜subjectKit 快速扩充**（低风险、高确定性）：chem + physics 直接加模块，复用动画/公式/示意图。
- **阶段 B｜FULL 既有分类补数据**（低风险）：给 earth/life/thought/mind/econ 的现有 JSON 分类**加条目**，把每类从 8–14 补到 15–25。
- **阶段 C｜FULL 新增分类视图**（需改模板，逐学科推进）：为 earth/life/thought 增补「原理/分支」类新数据集与对应视图。

优先级：`earth ≈ life > thought > chem > physics > mind > econ > dynasty`。

1. **双语完整**：每条 zh+en，无空壳；沿用 `esc`/`L()` 约定。
2. **深链稳定**：`id` 唯一，命名 `<域>-<主题>`（如 `earth-plate-tectonics`）。
3. **公式/动画**：化学方程式用 `eq`+`subs`；物理定律用 `eq:{rel:"equal"}`。
4. **图示**：关键概念补 SVG `figure`（玻尔模型/细胞/板块等）。
5. **计数同步**：改数据后更新该学科 `overview.json` 的 `counts`/`kpis`（FULL）；subjectKit 自动统计。文件命名与计数键的 kebab/camel 差异由 `check-links` 同义处理。
6. **派生数据重建**：FULL 改数据后跑 `npm run index:build -- <subject>`（search/related）；subjectKit 改 `data.ts` 后跑 `npm run data:export`；对外文案/收录清单跑 `npm run gen:geo && npm run gen:sitemap`。
7. **验证**：`npm run verify` = typecheck + `check:json` + `links:check`（死链/双语成对/英文混中文/派生索引覆盖/overview 计数）+ `data:check`（导出防漂移）+ dynasty 校验；再 `npm run build`。
8. **渲染约定（不在数据里造展示逻辑）**：公元前年份在数据里存负数，展示走共享 `yearText`（「前 450 年」/「450 BCE」）；英文态下 `L(it,'termEn')` 会与 `L(it,'term')` 同串，副行与主行重复则不渲染；轻量学科条目的 `related` 由 `subjectKit` 详情面板渲为可跳转的芯片。三处均为全站约定，新增模块时沿用而非另写。
9. **提交**：按学科/阶段分组提交并推送，信息含范围与条目数。
