## 0. 「极丰富」基准（以 dynasty 为标尺）

`dynasty` 现有 **19+ 主题数据集** + 21 个朝代分卷：朝代 / 人物 / 战役 / 大事件 / 典章制度 / 变法 / 都邑 / 文物 / 货币 / 文化 / 发明 / 成语 / 名言 / 地理 / 中外对照 / 统一进程 / 史料 / 检索 / 总览。

据此定义「极丰富」量化门槛（每学科）：

| 维度       | 门槛                                                    |
| ---------- | ------------------------------------------------------- |
| 主题模块数 | ≥ 12                                                    |
| 条目总数   | ≥ 150（理想 200–300）                                   |
| 双语       | 100%（zh + en）                                         |
| 每条目字段 | 术语 + 释义 + 深入 + 示例/现象 + 标签（尽量）           |

## 1. 现状与差距（2026-10 盘点）

两种架构并存，扩充手法不同：

- **subjectKit（LIGHTWEIGHT）**：`physics`、`chem` —— 配置驱动，加模块 = 往 `data.ts` 的 `modules[]` 追加，**最易扩充**，且已具备 `figure`/`eq`/动画/物质释义能力。
- **FULL 模板**：`dynasty`、`econ`、`mind`、`thought`、`earth`、`life` —— 自带 `template.ts` + `public/<x>-data/data/*.json`。加条目 = 改 JSON（易）；**加新分类视图 = 需改模板**（重）。

## 2. 执行策略（三阶段）

- **阶段 A｜subjectKit 快速扩充**（低风险、高确定性）：chem + physics 直接加模块，复用动画/公式/示意图。
- **阶段 B｜FULL 既有分类补数据**（低风险）：给 earth/life/thought/mind/econ 的现有 JSON 分类**加条目**，把每类从 8–14 补到 15–25。
- **阶段 C｜FULL 新增分类视图**（需改模板，逐学科推进）：为 earth/life/thought 增补「原理/分支」类新数据集与对应视图。

优先级：`earth ≈ life > thought > chem > physics > mind > econ > dynasty`。

## 5. 施工规范（每阶段必守）

1. **双语完整**：每条 zh+en，无空壳；沿用 `esc`/`L()` 约定。
2. **深链稳定**：`id` 唯一，命名 `<域>-<主题>`（如 `earth-plate-tectonics`）。
3. **公式/动画**：化学方程式用 `eq`+`subs`；物理定律用 `eq:{rel:"equal"}`。
4. **图示**：关键概念补 SVG `figure`（玻尔模型/细胞/板块等）。
5. **计数同步**：改数据后更新该学科 `overview.json` 的 `counts`/`kpis`（FULL）；subjectKit 自动统计。
6. **验证**：每阶段 `npm run typecheck && npm run build`；FULL 数据改动跑 `npm run verify`（含 JSON 校验）。
7. **提交**：按学科/阶段分组提交并推送，信息含范围与条目数。
